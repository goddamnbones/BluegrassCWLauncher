        What's new
        
0.1.11

        
    
          
  • Shenandoah and Shenandoah generational garbage collectors.
    • 
          
  • Advanced: G1 pause target, code cache and metaspace are their own settings.
    • 
          
  • The JVM box holds only your extra flags and no longer resets on save or while you type; the full launch line is shown below it.
    • 
          
  • Flags are checked with the game's own Java before saving, so a typo can't break your launch.
    • 
          
  • Manual override: set the whole JVM line yourself.
    • 
        

        
0.1.10

        
    
          
  • PZO now installs the latest release from GitHub; any installed PZO is used at launch.
    • 
        

        
0.1.9

        
    
          
  • The JVM settings box shows the full line the next launch uses again, and Default puts the standard line back.
    • 
        

        
0.1.8

        
    
          
  • JVM tuner: game memory and garbage collector (G1, or ZGC for trials) are now their own settings, with a warning when memory is set above what's safe for your PC.
    • 
          
  • Flags from your own ProjectZomboid64.json (often added by PZO) are listed once so you can keep or drop each for launcher launches.
    • 
        

        
0.1.6

        
    
          
  • Diagnostics panel for when staff ask: native memory tracking, launch without PZO, PZO texture handoff off, PZO FSR off.
    • 
        

        
0.1.5

        
    
          
  • Uninstall button for ZombieBuddy and PZO: removes the approved files from the game folder (asks first).
    • 
        

        
0.1.4

        
    
          
  • More memory for the game on big PCs: 32 GB PCs now get 12 GB (was 10), 64 GB+ PCs get 16 GB (was 12). Fixes heavy stutter when zoomed out while driving at high resolutions.
    • 
        

        
0.1.3

        
    
          
  • Potato Mode checkbox: lower graphics settings on Bluegrass for low-end PCs; your own settings come back when you leave.
    • 
        

        
0.1.2

        
    
          
  • System RAM dropdown: sets how much memory the game gets. 8 GB PCs now get 4 GB by default (was 6), 64 GB+ PCs get 12 GB.
    • 
          
  • Optional Java profile (JFR) checkbox for when staff ask for one; recordings go to C:\BGjfr.
    • 
          
  • New look, matching the Bluegrass admin menu.
    • 
          
  • Updates now show what changed before you install them.
    • 
        

        
0.1.1

        
    
          
  • Fixed console windows flashing and the launcher freezing while it checked whether the game was running.
    • 
        

        
0.1.0

        
    
          
  • First release: installs the approved ZombieBuddy and PZO, launches the game with them, leaves Steam launches as they were.
